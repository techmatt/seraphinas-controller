# systems — Seraphina's Secret

*A compact index of the machinery, so claude.ai can write prompts without the state doc bloating. One line per system: enough to know a thing exists and what its shape is. The detail lives in the MAIN repo's `docs/systems.md` and `docs/engineering.md` (CC-maintained) — cite those by path in prompts. New at checkpoint 6, 2026-08-13.*

- **Session store**: `run` / `world` / `persistent` halves; `resetForSleep` clears run+world and keeps persistent (coins); a cold `reset()` clears all; `run.completed` is the set of quests finished today. Session-scoped — a page reload is still a fresh day.
- **Quest engine**: thought-bubble two-press offers (the second press IS acceptance); phase goal kinds travel / gather / chop-count / lure-follower / book / park (an instruction-less phase ends the quest); one active quest absolute; `inPlay()` = active + finished-today. **Quest furniture is runtime-spawned and invisible to `world:build` and the static grid checks** — placement is hand-held against it (the gate is parked).
- **Book reader**: takeover two-page spread (`ui/BookReader.ts`); pages auto-read through `WordRibbon` (the highlight engine split out of `SpeechBubble` — one engine, two surfaces); green turns after the read, yellow re-reads, red closes with the page held; book data in `content/books/`, page art side-loaded per the world/design docs.
- **Followers**: leash machinery (faeries, bunnies), off-grid, no collision, 250 px/s.
- **Voice**: TWO providers — Adobe Firefly (primary; Matt records batches by hand in the web UI) + edge-tts (fallback and authoring voice). Firefly timings come from forced alignment (`tools/voice/align/`; CTC latency constant applied in-tool, model-specific). The loop: `voice:batch` → paste per `content/voice/profiles.json` → save the WAV beside the .txt → `voice:ingest` (cut at silence, normalize −19 dBFS, provenance, latest-wins) → `voice:build` (hash-guarded: stale or missing → LOUD edge-tts fallback) → `voice:status`. Also: `voice:audit` (the dialog CSV), `voice:inspect` (Chromium decode + timing proof), `voice:simulate` (regression without Firefly), and the in-game debug view on keyboard `V`. Prompt-facing rules — no mid-line `!` or `.` (use the say/text split), trailing punctuation is free; pre-cut lines only, so no dynamic numbers; the rebuild fingerprint excludes the speaker id (renaming the LINE id is what forces a re-cut).
- **Art**: measure sheets, never assume; pack readmes are license-only; the bunny swap contract is the constants atop `src/world/Bunny.ts`.
- **Suite**: 20 tests (15 fast ~6.1–6.8 min, 5 @slow, `test:all` ~7.8 min); 150 s per-test cap with ONE exception — the merged two-quest e2e carries its own 180 s timeout after biting the cap once. Lean-suite rules: shared boots, teleport where the walk is not what's under test, cut what Matt's play would catch.
- **Day cycle**: sleep → quests and quest furniture despawn, world regenerates, run+world reset; then dusk. Recap priority faeries > bunnies > stones/trees/errand, max 2 lines + the goodnight.
- **Coins**: `addCoin`, 3 slots, overflow bounce; the grant settles state instantly and defers the flourish.
